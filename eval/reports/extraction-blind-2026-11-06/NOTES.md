# Fresh blind extraction set (2026-11-06)

`eval/data/extraction_blind_2026-11-06.jsonl` contains 80 answers, with 20 each in English,
Hindi, Marathi and Hinglish. The source was mechanically validated before it was copied: 80 valid
JSON records, all required fields and values accepted, 20 records per language, and all 14 probes
represented. No source text or labels needed mechanical correction.

An AI model wrote the set outside the repository from the author brief and probe questions only. It
had no access to the extractor rules or prior failures and is not a native speaker. A second AI
model independently re-labelled the set blind, changed one hedge label, and revised one Marathi
sentence without changing its labels. Neither model is a native speaker. Native-speaker review is
pending.

The dataset was committed as `a4c4238d4605ba785d418c614ad8ef31bdeaf919` in commit
`Add a fresh blind extraction set` before the scorer was run on it. This report records the initial
rules-only result at that commit. No extractor changes were made in this branch.

## Reading and limits

This initial score shows that the rules often miss these AI-written answers and sometimes produce
an unsupported definite outcome. The seven invented outcomes matter more than the twenty misses,
since misses cost another question while invented evidence can mislead the investigation. The one
wrong outcome is in Hinglish. These findings are examples to investigate in a later extractor
change. Any tuning against this set makes it no longer blind; subsequent results must say that.

The set contains AI-written synthetic text, not real participant speech. It does not measure ASR
errors, live speech recognition, or native-speaker quality. Native-speaker review is pending.
