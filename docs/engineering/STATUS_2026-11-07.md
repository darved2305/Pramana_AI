## Fixes and limitations

- Presence media turns now expose their question kind and no probe choices or ASR hints. A
  failing protocol regression advertised `up`/`tripped` for a label reading. The honest and
  cannot-read variants now cross the media socket and produce the expected presence result.
- Participant filtering now removes staff-only reconciliation explanations and other people's
  presence results. Regression tests cover S1 and S2; real-stack browser tests use actual
  participant tokens to check the HTTP response.
- The voice runner supports all three scenarios, synthesises dynamic presence readings and
  English S2 answers, cancels obsolete speakers, closes clients and propagates bot errors. Its
  pass criterion includes the scenario outcome, correct reveal where a decision was made,
  commitment verification, replay and absence of call errors.
- The first live S7 adversary attempt **failed** because the runner used `cctv_screen` instead
  of the pack's `nvr_screen`, then timed out in silence. `voice-S7-adversary.json` preserves the
  failed result. The corrected run and the probe regression passed; this was not called flaky.
- Text rehearsal reports now retain `status_before_reveal`. S7's abstention must remain visible
  after reveal closes the investigation.
- The console now offers breaker repair only for the supported electrician-dispatch decisions
  with an electrician participant, and explains why other diagnoses have no action here. The
  server already rejects unindicated actions; the UI now avoids offering that dead end.
- S2's first voice take accidentally used the shared Hinglish text phrases under English TTS.
  English phrases are now shared by text/voice helpers and checked against every probe's
  extractor outcomes. The corrected live take passed; the original result is preserved honestly.
- Benchmark reports now show completed episodes and excluded failed runs for every policy.
  The LLM policy prompt and its cache keys were not changed.
- CI now includes evaluation typing, the audio-worklet check, and a separate real-stack browser
  job with PostgreSQL and failure artifacts. Passing local checks do not establish remote CI.
