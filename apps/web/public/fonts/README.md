# Licensed reference fonts

The reference design uses two commercial typefaces that cannot be committed here:

| Family        | Files to place in this folder                                   | Source |
|---------------|------------------------------------------------------------------|--------|
| PP Right Slab | `PPRightSlab-Light.woff2` (300), `PPRightSlab-Regular.woff2` (400) | pangrampangram.com |
| FT Activica   | `FTActivica-Regular.woff2` (400)                                  | the foundry's site |

`.woff`, `.otf` files with the same base names also work. When present, they are loaded
automatically at the next server start and replace the open-licensed stand-ins
(Zilla Slab, Geist Pixel). Do not commit the font files unless your license allows it.
